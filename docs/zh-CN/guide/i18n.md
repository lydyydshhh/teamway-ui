# 国际化

TeamwayUI 组件**默认**使用中文。 如果你想使用其他语言，请继续阅读以了解具体方法。

## 全局配置

TeamwayUI 提供了全局配置选项。

```ts [main.ts]
import TeamwayUI from 'teamway-ui'
import zhCn from 'teamway-ui/es/locale/lang/zh-cn'

app.use(TeamwayUI, {
  locale: zhCn,
})
```

## ConfigProvider

TeamwayUI 还提供了一个 Vue 组件 [ConfigProvider](/en-US/component/config-provider) 用于全局配置国际化的设置。

```vue [App.vue]
<template>
  <ty-config-provider :locale="zhCn">
    <app />
  </ty-config-provider>
</template>

<script setup lang="ts">
import { TyConfigProvider } from 'teamway-ui'
import zhCn from 'teamway-ui/es/locale/lang/zh-cn'
</script>
```

## 日期和时间本地化

我们使用 [Day.js](https://day.js.org/docs/en/i18n/i18n) 库来管理组件的日期和时间，例如 `DatePicker`。 在 Day.js 中设置合适的语言也非常重要，这样才能确保国际化功能正常工作。 您必须分开导入Day.js的区域设置。

```ts
import 'dayjs/locale/zh-cn'
```

完整文档请参阅：[ConfigProvider](/zh-cn/component/config-provider)
